Định Kiểu Danh Sách Trong CSS

Tổng hợp thuộc tính list-style-type, list-style-position, list-style-image & thuộc tính rút gọn list-style

📌 1. Thuộc tính list-style-type (Đánh dấu mục danh sách khác nhau)

ul { list-style-type: square; }
ol { list-style-type: upper-roman; }

UL - Kiểu Square (Hình vuông):

  • HTML5 & CSS3
  • JavaScript ES6+
  • React & Next.js

OL - Kiểu Upper-Roman (Chữ La Mã):

  1. Lên kế hoạch dự án
  2. Thiết kế UI/UX
  3. Lập trình & Đóng gói

📌 2. Thuộc tính list-style-position (Vị trí dấu bullet: inside / outside)

ul.outside { list-style-position: outside; } /* Mặc định: Dấu bullet ở ngoài lề nội dung */
ul.inside { list-style-position: inside; } /* Dấu bullet nằm bên trong dòng nội dung */

Vị trí Outside (Bên ngoài):

  • Phần tử danh sách 1 với vị trí bullet outside. Khi văn bản kéo dài xuống dòng, dấu bullet nằm hoàn toàn ngoài lề văn bản.
  • Phần tử danh sách 2.

Vị trí Inside (Bên trong):

  • Phần tử danh sách 1 với vị trí bullet inside. Khi văn bản kéo dài xuống dòng, dấu bullet nằm bên trong dòng nội dung.
  • Phần tử danh sách 2.

📌 3. Thuộc tính rút gọn list-style (Shorthand Property)

/* Thứ tự giá trị: type position image */
ul { list-style: square inside; }
  • Danh sách áp dụng thuộc tính rút gọn list-style: square inside;
  • Giúp viết mã CSS ngắn gọn và tối ưu hơn.

📌 4. Định kiểu danh sách kết hợp màu sắc (Color Styling)

ol { color: #fbbf24; } /* Màu sắc của thẻ ol sẽ áp dụng cho số đếm bullet */
ol li { color: #f8fafc; } /* Màu sắc thẻ li áp dụng cho văn bản nội dung */
  1. Bước 1: Phân tích yêu cầu bài toán.
  2. Bước 2: Xây dựng cấu trúc trang với HTML5.
  3. Bước 3: Định kiểu giao diện với CSS3.
