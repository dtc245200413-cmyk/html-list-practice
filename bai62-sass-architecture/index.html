Chi Tiết 7 Thư Mục Trong Kiến Trúc SASS 7-1

01

abstracts/

Chứa các khai báo toàn cục không tạo ra mã CSS trực tiếp như biến (_variables.scss), mixins (_mixins.scss) và functions (_functions.scss).

02

base/

Chứa các thiết lập CSS mặc định cho toàn bộ trang web như reset CSS (_reset.scss), typography (_typography.scss) và quy tắc global.

03

layout/

Quản lý các khối bố cục chính của giao diện bao gồm header (_header.scss), footer (_footer.scss), navigation và grid system.

04

components/

Chứa style cho các thành phần UI nhỏ tái sử dụng nhiều lần như nút bấm (_buttons.scss), thẻ card (_cards.scss), modals, badges.

05

pages/

Chứa các đoạn CSS chỉ áp dụng riêng biệt cho từng trang cụ thể như trang chủ (_home.scss), trang giới thiệu (_about.scss), liên hệ.

06

themes/ & vendors/

Quản lý các chủ đề giao diện (_light.scss, _dark.scss) và tích hợp các thư viện CSS bên thứ 3 (Bootstrap, Font Awesome).
