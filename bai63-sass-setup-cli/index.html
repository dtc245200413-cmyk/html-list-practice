SASS / SCSS CLI SETUP GUIDE

Cài Đặt & Sử Dụng SASS CLI

Hướng dẫn toàn diện về Node.js, npm và SASS Command Line Interface

1. Các Bước Cài Đặt Node.js & SASS CLI

01

Kiểm Tra Node.js

Kiểm tra xem máy tính đã có Node.js và npm hay chưa bằng Terminal:

node -v
npm -v
02

Cài Đặt SASS Global

Sử dụng npm để cài đặt SASS trên toàn hệ thống:

npm install -g sass
03

Kiểm Tra Phiên Bản

Xác nhận SASS đã sẵn sàng sử dụng:

sass --version

2. Lệnh Biên Dịch SASS CLI & Watch Mode

⚡

Biên Dịch File Đơn

Chuyển đổi một file SCSS sang CSS:

sass scss/styles.scss css/styles.css
👀

Chế Độ Watch Mode

Tự động biên dịch khi lưu tệp SCSS:

sass scss/styles.scss css/styles.css --watch
📁

Biên Dịch Thư Mục

Biên dịch toàn bộ thư mục SCSS sang CSS:

sass scss/:css/ --watch

3. Tích Hợp npm Scripts Trong package.json

Để chuyên nghiệp hóa quy trình phát triển, ta có thể định nghĩa các lệnh chạy trong package.json:

"scripts": {
  "build:css": "sass scss/:css/ --no-source-map",
  "watch:css": "sass scss/:css/ --watch"
}

Khi phát triển dự án, chỉ cần chạy lệnh ngắn gọn trong Terminal:

npm run watch:css
