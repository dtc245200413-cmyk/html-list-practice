Nội Dung Chính (Main Content)

Bố cục trang web này áp dụng chuẩn Bootstrap Containers và hệ thống lưới Grid System (row, col-lg-8, col-lg-4, col-12).

Trên màn hình máy tính lớn (≥ 992px), phần Nội dung chính chiếm 8 cột (col-lg-8) và Sidebar chiếm 4 cột (col-lg-4). Khi thu nhỏ màn hình di động (< 992px), các cột tự động xếp chồng dọc gọn gàng (col-12).
