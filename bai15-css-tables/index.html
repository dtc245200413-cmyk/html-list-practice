Định Kiểu Bảng Trong CSS (CSS Table Styling)

Hướng dẫn & Thực hành các thuộc tính border, border-collapse, width, height, text-align, vertical-align & padding

📌 1. Đường viền bảng (Border & Border-collapse)

Mặc định khi đặt border cho table, th, td sẽ tạo ra đường viền đôi. Sử dụng border-collapse: collapse; để hợp nhất thành một đường viền đơn sắc nét.

Viền đôi (Chưa dùng collapse):

Họ tênTuổi
Nguyễn Văn A20
Trần Thị B22

Viền đơn (Dùng border-collapse: collapse):

Họ tênTuổi
Nguyễn Văn A20
Trần Thị B22

📌 2. Kích thước, Căn chỉnh (text-align / vertical-align) & Padding

table { width: 100%; border-collapse: collapse; }
th { height: 50px; text-align: left; background-color: #2563eb; }
td { padding: 14px; vertical-align: bottom; }
