Thực hành Refactoring CSS thành SASS Modules với Biến, Mixins & Nesting

📌 1. So Sánh Mã CSS Ban Đầu vs SCSS Đã Refactor

Trước khi refactor, mã CSS viết phẳng (flat) dễ bị trùng lặp màu sắc, kích thước và không thể tái sử dụng logic. Sau khi chuyển đổi sang SASS:

  • • Quản lý màu sắc tập trung bằng biến $primary-color, $text-color.
  • • Đóng gói style nút bấm & shadow bằng Mixins @mixin button-style, @mixin box-shadow.
  • • Chia nhỏ thành các Partials (_variables.scss, _mixins.scss, _cards.scss).
