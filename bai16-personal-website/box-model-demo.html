Minh Họa Mô Hình Hộp (CSS Box Model)

Phần tử bên dưới có thuộc tính: width=200px, padding=35px, border=20px, margin=25px.

Content demo box

Công Thức Tính Tổng Chiều Rộng:

Tổng width = width + (padding-left + padding-right) + (border-left + border-right) + (margin-left + margin-right)

= 200 + (35 + 35) + (20 + 20) + (25 + 25) px

= 200 + 70 + 40 + 50 = 360px
