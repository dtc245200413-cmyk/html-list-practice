Responsive Grid System (SASS Refactored)

Tái cấu trúc mã nguồn CSS Grid truyền thống sang mô hình SASS Modules & Mixins

1. Bố Cục 4 Cột (Hệ Thống Lưới 12 Cột SASS)

01

Cột 1 (col-lg-3)

Tự động chiếm 3/12 cột trên màn hình Desktop lớn, 6/12 trên Tablet và 12/12 trên Mobile.

02

Cột 2 (col-lg-3)

Tạo tự động bằng vòng lặp SASS @for $i from 1 through 12 giúp mã vô cùng ngắn gọn.

03

Cột 3 (col-lg-3)

Sử dụng SASS Map $breakpoints và Mixin respond-min() để quản lý media queries.

04

Cột 4 (col-lg-3)

Tối ưu hóa khả năng bảo trì, thay đổi khoảng cách Gutter duy nhất bằng 1 biến $gutter-width.

2. Bố Cục Bài Viết & Sidebar (Tỷ Lệ 8 : 4)

Nội Dung Bài Viết Chính (col-lg-8)

• Bằng cách sử dụng SASS để tái cấu trúc lại mã CSS Grid truyền thống, chúng ta có thể loại bỏ hoàn toàn việc lặp lại hàng trăm dòng mã CSS thủ công cho từng độ phân giải màn hình.

• Vòng lặp @for trong SASS sẽ tự động sinh ra tất cả các class từ .col-1 đến .col-12 cùng với các biến thể responsive như .col-md-* và .col-lg-*.
