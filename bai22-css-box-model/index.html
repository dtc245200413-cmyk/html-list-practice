Bài Tập Mô Hình Hộp CSS (Box Model)

So sánh sự khác biệt giữa box-sizing: content-box và box-sizing: border-box

Thẻ 1: content-box

Màu xanh lá (#2ecc71)

Kích thước thực tế: 330px x 200px (Kích thước bị phình to ra vì cộng thêm padding & border).

Thẻ 2: border-box

Màu vàng (#f1c40f)

Kích thước thực tế: 280px x 150px (Kích thước giữ nguyên chuẩn theo width & height đã đặt).

Thẻ 3: border-box

Màu đỏ (#e74c3c)

Kích thước thực tế: 280px x 150px (Giữ nguyên chuẩn 280x150px, dễ kiểm soát bố cục layout).
